# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Guests booking short-term accommodations for their trips, and Hosts managing their listed properties and bookings (Airbnb clone model).

## Product Purpose
ESQOUN is a comprehensive two-sided booking platform that makes it possible for users to easily rent properties as guests or list and manage properties as hosts. Success means providing a seamless, trusted experience for both roles.

## Positioning
ESQOUN competes on clean, modern UX and robust features, enabling a unified platform where a single user can smoothly transition between being a guest and a host.

## Operating Context
Users access the platform via web browsers on desktop and mobile devices to discover stays, book trips, and manage properties. 

## Capabilities and Constraints
- Must preserve the existing Next.js and Tailwind CSS frontend stack.
- Must preserve the existing NestJS backend API contracts.
- Must support the complex dual-role system (guest/host).

## Brand Commitments
- Must strictly maintain the "ESQOUN" brand identity, name, and tone.

## Evidence on Hand
- Existing Next.js codebase with functional UI components.
- Established workflows for OTP email authentication, registration, login, and forgot-password flows.
- Implemented features for booking management, unit creation, and reviews.
